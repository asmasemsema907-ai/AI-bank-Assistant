# AI Bank Assistant

AI Bank Assistant is a local Retrieval-Augmented Generation (RAG) application for banking customer-service and policy questions. It combines a 1,000-row banking knowledge base, hybrid retrieval, ChromaDB persistence, Ollama-based local generation, and a Streamlit dashboard with a floating chatbot interface.

The app is designed for local demos, internal pilots, and as a foundation for a commercial banking assistant. It does not require an external LLM API key when run with Ollama.

## Features

- Banking knowledge base loaded from `banking_knowledge_base_1000.csv`.
- Hybrid retrieval using BM25 lexical search and dense embeddings.
- Multilingual semantic retrieval with `sentence-transformers/paraphrase-multilingual-MiniLM-L12-v2` when the model is available locally.
- Local TF-IDF fallback when the transformer embedding model is not cached.
- Persistent ChromaDB vector store under `chroma_db/`.
- English and Arabic answer support based on the user's question language.
- Ollama integration through the local `/api/generate` endpoint.
- Streamlit dashboard with knowledge-base metrics, retrieval status, model status, sample prompts, and floating chat widget.
- Offline-friendly preprocessing with bundled WordNet data and safe tokenizer/stopword fallbacks.
- Environment-driven configuration through `.env` and optional Streamlit secrets.

```text
hybrid_score = 0.4 * BM25 + 0.6 * embedding_similarity
```

## Project Structure

| File | Purpose |
| --- | --- |
| `01_documents.py` | Loads banking Q&A records from the CSV file into a shared `documents` list. |
| `02_preprocessing.py` | Normalizes text, tokenizes, removes stopwords, and lemmatizes with safe offline fallbacks. |
| `03_chunking.py` | Splits each document into overlapping chunks for retrieval. |
| `04_vector_representation.py` | Builds BM25, embeddings, multilingual query bridging, and hybrid search. |
| `05_create_chroma_store.py` | Creates or updates the persistent ChromaDB store. |
| `06_retrieve_context.py` | Selects top sources and formats context blocks for the prompt. |
| `07_prompting.py` | Builds prompts, calls Ollama, handles language selection, and returns grounded answers. |
| `streamlit_app.py` | Streamlit dashboard and floating chatbot UI. |
| `banking_knowledge_base_1000.csv` | Source knowledge base with 1,000 banking Q&A rows. |
| `.env.example` | Local environment variable template. |
| `requirements.txt` | Python package dependencies. |
| `VSCODE_SETUP.md` | VS Code-specific setup notes. |

Generated/local folders:

| Path | Purpose |
| --- | --- |
| `chroma_db/` | Persistent vector database generated by ChromaDB. |
| `venv/` | Local Python virtual environment. Do not commit it. |
| `__pycache__/` | Python bytecode cache. Do not commit it. |
| `nltk_data/` | Bundled NLTK WordNet data used for offline lemmatization. |

## Requirements

- Python 3.10 or later.
- Ollama installed and running.
- An Ollama model pulled locally, default: `llama3.1`.
- Windows PowerShell, macOS terminal, or Linux shell.

## Environment Variables

Create a local `.env` file from `.env.example`.

| Variable | Default | Description |
| --- | --- | --- |
| `OLLAMA_HOST` | `http://localhost:11434` | Base URL for the Ollama server. |
| `OLLAMA_MODEL` | `llama3.1` | Ollama model used for generation. |
| `ALLOW_MODEL_DOWNLOAD` | `false` | Set to `true` only when the server may download Hugging Face models during setup. |

Keep `.env` and `.streamlit/secrets.toml` out of version control.

## Local Setup on Windows

From PowerShell:

```powershell
cd "D:\RAG\rag_lab_v2_project (1)"

python -m venv venv
.\venv\Scripts\Activate.ps1

python -m pip install --upgrade pip
pip install -r requirements.txt

Copy-Item .env.example .env
```

Install Ollama from:

```text
https://ollama.com/download
```

Then pull the default model:

```powershell
ollama pull llama3.1
```

If the Ollama desktop app is not already running, start the server:

```powershell
ollama serve
```

In a second terminal, run the Streamlit app:

```powershell
cd "D:\RAG\rag_lab_v2_project (1)"
.\venv\Scripts\Activate.ps1
streamlit run streamlit_app.py
```

Streamlit will print a local URL, usually:

```text
http://localhost:8501
```


## How Retrieval Works

1. `01_documents.py` reads each row from `banking_knowledge_base_1000.csv`.
2. `02_preprocessing.py` normalizes text for search.
3. `03_chunking.py` creates overlapping text chunks.
4. `04_vector_representation.py` computes:
   - BM25 keyword scores.
   - Embedding similarity scores.
   - A weighted hybrid score.
5. `06_retrieve_context.py` selects the best unique sources and formats them as `[Source 1]`, `[Source 2]`, etc.
6. `07_prompting.py` sends the grounded context and user question to Ollama.
7. `streamlit_app.py` displays the answer and source labels in the chatbot.
